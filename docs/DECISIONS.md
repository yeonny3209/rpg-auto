# 결정 기록

형식: `날짜 — 결정 — 이유`

## 2026-11-27 (첫 실행)
- **기술 스택: TypeScript + Three.js + Vite** — 웹 브라우저 3D 표준에 가깝고, 무료이며, 이 클라우드 환경에서 Node로 빌드하고 Playwright(헤드리스 Chromium)로 실행·스크린샷 검증까지 가능하다. Unity/Godot은 이 환경에서 실행 검증이 어렵다.
- **테스트: Vitest** — Vite와 설정을 공유하고 빠르다. 게임 로직(`src/logic/`)만 테스트 대상으로 한다.
- **로직/렌더링 분리** — `src/logic/`은 Three.js를 import하지 않는다. 밸런스 수치는 `data/*.json`.
- **물리 엔진 없음(초기)** — 평지 + 간단한 원형 충돌로 시작. 지형·복잡한 충돌이 필요해지면 그때 검토(Rapier 등 무료 WASM).
- **게임 이름 "잔불의 대지"** — 빛/어둠 대비를 시각·시스템(봉화, 잔불) 양쪽에 쓰기 위해.
- **최대 레벨 40, 시작 클래스 3종 + 15레벨 전문화** — 1인 개발·자동 개발 범위에서 끝까지 만들 수 있는 크기로 제한.
- **죽음 페널티는 미각인 잔불 50%만** — 긴장감은 주되 장비·경험치 손실로 좌절시키지 않기 위해.
- **에셋은 코드 생성 도형만** — 저작권 문제 원천 차단. 추후에도 CC0 등 출처 명확한 것만.
- **멀티플레이는 후반** — 1인용 수직 슬라이스가 재미있어진 뒤 WebRTC 협동을 검토.
- **상호작용 키 F (GDD의 E에서 변경)** — E는 카메라 회전(Q/E)에 쓰기로 해서 충돌을 피함. GDD 조작 표도 수정.
- **우클릭 = 강공격 차지, 휠클릭 드래그 = 카메라 회전** — 마우스 두 버튼을 모두 공격에 써서 손이 키보드 홈 위치를 떠나지 않게.
- **잔불 각인 비용은 레벨마다 20씩 증가(20, 40, 60…), 레벨당 공격력 +1%·최대 HP +3** — 초반엔 빨리 체감, 후반엔 완만하게.
- **사망 시 기존 흔적은 사라지고 새 흔적만 남음** — 소울류 규칙. 긴장감 유지.
- **저장은 localStorage + 버전 필드 + 단계별 마이그레이션(v1→v2→v3)** — 서버 없이 무료, 구조가 바뀌어도 기존 저장을 살림.
- **아이템 등급 가중치 60/28/9/2.6/0.4** — 전설은 약 250개 중 1개. 보스·엔드 콘텐츠에서 luck 보정으로 올릴 예정.
- **`window.__game` 디버그 핸들 유지** — 헤드리스 검증 스크립트가 게임 상태를 직접 확인하기 위해. 플레이에는 영향 없음.

## 2026-11-28 (2번째 실행)
- **`main.ts`를 모듈로 분리, 공유 상태는 `core.ts`에 둔다** — 모든 모듈이 `core`에서 가져가고 `core`는 다른 모듈을 import하지 않는다(타입만 예외). 모듈끼리 서로 호출하는 순환은 함수 호출 시점에만 일어나서 안전하다.
- **클래스는 "보너스 합산 + 공격 배율" 방식** — 장비 보너스와 같은 모양(`GearBonus`)으로 더하고, 공격 범위·각도·속도·스태미나는 배율로 바꾼다. 클래스별 시작 속성 포인트 합은 같게 해서 공정하게 시작.
- **기존(v3) 저장은 선봉으로 이어가고, 클래스 없는 저장은 선택 화면을 다시 띄운다** — 저장 호환을 지키면서 새 시스템 도입.
- **스킬은 4종 효과 타입(arc/ring/dash/buff)을 데이터로 조합** — 새 스킬을 코드 없이 JSON으로 추가할 수 있게. 스킬 적중은 잔불 게이지를 채우지 않는다(무한 연쇄 방지).
- **퀘스트 목표는 처치/봉화 점화 두 종류로 시작** — 이벤트 보고 한 줄(`reportQuest`)로 연결. 아이템 수집·대화 목표는 필요해질 때 추가.
- **저장 데이터는 읽을 때 `sanitize`로 정리** — 알 수 없는 퀘스트·초과 진행도는 버려서 데이터가 바뀌어도 저장이 깨지지 않게.
- **지형은 값 노이즈 3옥타브 × 평탄화 마스크, 높이 y는 매 프레임 `heightAt`으로 갱신** — 물리 엔진 없이 시각적 굴곡만. 마을·봉화 주변은 완전 평지라 기존 배치와 충돌 없음.
- **시작 지점 적 배치는 `?demo`에서만** — 일반 플레이 첫 화면을 조용하게, 테스트는 결정적으로.
- **튜토리얼 진행도는 별도 localStorage 키** — 게임 저장 형식을 또 올리지 않기 위해.
